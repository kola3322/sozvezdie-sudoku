# Созвездие судоку

Браузерная игра для детей и взрослых: числа или фигуры, пять уровней сложности, приключение из 50 заданий и бесконечная игра со счётом.

Оформление: Manrope (локальные файлы и SIL Open Font License в `docs/fonts/`), логотип «Линия созвездия» с красной точкой цвета сердечка. Компактная шапка без навигационных пунктов; после последнего ответа на телефоне кнопка проверки при необходимости прокручивается в видимую область.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173.

## Публикация на GitHub Pages

Сайт публикуется из папки `docs/` ветки `main`. В Settings → Pages выбран Deploy from a branch, main, /docs. После изменения файлов в этой папке и отправки изменений в main GitHub обновляет сайт автоматически.

Все пути к ресурсам относительные; игра работает по адресу проекта GitHub Pages. Генератор запускается в модульном Web Worker. Сервер и база данных не требуются.

## Проверка

```sh
npm test
```

Проверки охватывают единственность решения, логическую решаемость, границы уровней, баллы, исправления, подсказки и очистку. На первом уровне 9 исходных клеток, на втором — 6.

## Сохранения

Прогресс хранится в localStorage текущего браузера и привязан к адресу сайта. При переходе с другого домена он автоматически не переносится. Очистка данных браузера удаляет сохранение.

Секреты и токены не нужны для работы игры и не должны попадать в репозиторий.
