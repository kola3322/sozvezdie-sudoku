# Созвездие судоку

Браузерная игра для детей и взрослых: числа или фигуры, пять уровней сложности, приключение из 50 заданий и бесконечная игра со счётом.

Оформление: Manrope (локальные файлы и SIL Open Font License в `docs/fonts/`), логотип «Линия созвездия» с красной точкой цвета сердечка. Компактная шапка без навигационных пунктов; после последнего ответа на телефоне кнопка проверки при необходимости прокручивается в видимую область.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173.

## Генератор для печати

Кнопка «Судоку для печати» в стиле «Лёгкий контур» находится только в шапке главной страницы. [Открыть генератор](https://kola3322.github.io/sozvezdie-sudoku/print.html). Локальный адрес после запуска: http://127.0.0.1:4173/print.html.

Можно выбрать 1–50 задач, поле 4×4 / 6×6 / 9×9, точное число исходных клеток, числа или фигуры, формат А4 / А5. Цветная печать доступна только для фигур. Все клетки белые; на каждом листе сверху слева находятся логотип и название. Раскладка сохраняет поля 12 мм и клетки не менее 9 мм. Кнопка «Печатать» открывает окно браузера, где также можно сохранить PDF. Выберите соответствующую бумагу, масштаб 100% и отключите браузерные колонтитулы.

Задачи имеют единственное решение. Генерация работает в отдельном Worker, поддерживает отмену, не меняет игровой прогресс и не выдаёт неполный набор. Изменение сетки, числа задач или исходных клеток требует повторной генерации. Смена символов, цвета и бумаги сохраняет задачи.

Ползунок «Размер задачи на листе» изменяет физическую сторону поля в миллиметрах и сразу пересчитывает страницы, сохраняя задачи. Кнопка «Обычный» возвращает стандартный размер. При выборе более маленькой бумаги размер при необходимости автоматически ограничивается. Повторная генерация нужна при смене сетки (4×4 / 6×6 / 9×9), но не при изменении её печатного размера.

Подробные требования: [PRINT_SPECIFICATION.md](PRINT_SPECIFICATION.md).

## Публикация на GitHub Pages

Сайт публикуется из папки `docs/` ветки `main`. В Settings → Pages выбран Deploy from a branch, main, /docs. После изменения файлов в этой папке и отправки изменений в main GitHub обновляет сайт автоматически.

Все пути к ресурсам относительные; игра работает по адресу проекта GitHub Pages. Генератор запускается в модульном Web Worker. Сервер и база данных не требуются.

## Проверка

```sh
npm test
```

Проверки охватывают единственность решения, логическую решаемость, границы уровней, баллы, исправления, подсказки и очистку. На первом уровне 9 исходных клеток, на втором — 6.

Тесты печатного генератора проверяют точное число исходных клеток, единственное решение на минимальных, стандартных и максимальных настройках, исключение повторов, валидацию, ограничение времени и вместимость листов. Дополнительно локально проверены интерфейс Chrome при ширине 320–1440 px и сохранение PDF обоих форматов. Реальный iPhone/Safari и физический принтер в эту проверку не входят.

## Сохранения

Прогресс хранится в localStorage текущего браузера и привязан к адресу сайта. При переходе с другого домена он автоматически не переносится. Очистка данных браузера удаляет сохранение.

Секреты и токены не нужны для работы игры и не должны попадать в репозиторий.
